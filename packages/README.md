# Packages

This folder contains lightweight package skeletons for the native tools foundation.

Current packages:

- `@jenan/visual-dna` — wrapper for `services/visual-dna`
- `@jenan/pdf-engine` — PDF utilities
- `@jenan/docs-engine` — DOCX utilities
- `@jenan/sheets-engine` — XLSX utilities
- `@jenan/token-compiler` — token compiler engine
