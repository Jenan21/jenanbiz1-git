# Jenan PRO Canonical Homepage Reference

`homepage.png` is the sole binding visual reference for the public homepage at `/`.

## Authority

- This reference supersedes every older Home, landing, pre-entry, experimental, and alternate homepage design.
- Production must recreate the design with real React, CSS, SVG, live components, and truthful data states. The image must never be loaded as a production background.
- The approved Jenan PRO identity, hero composition, six service cards, ecosystem strip, market strip, color harmony, lighting, depth, typography, and hierarchy define the canonical direction.
- Elements intentionally removed by prior product decisions must not be restored merely because an older reference contains them.
- `/home` may exist only as a compatibility redirect to `/`; it must not implement another homepage.
- Authentication overlays reuse this homepage as their surrounding scene while retaining the approved login and registration panels.
