Jenan PRO — PAGE-BY-PAGE UI REFERENCE PACKAGE

هذه الحزمة مرجع واجهات كامل صفحة بصفحة.

الهوية الحالية: Jenan PRO / جنان برو فقط.
أي Jenan BIZ داخل المراجع القديمة = مرجع بصري قديم فقط ولا يُنسخ.

كل صفحة داخل مجلد مستقل وتحتوي:
- reference.html : تصميم Responsive مستقل يمكن فتحه بالمتصفح.
- spec.txt       : مكونات الصفحة ومخرجاتها وانتقالاتها.

قواعد التنفيذ:
- لا تستخدم صور المراجع كخلفية Production.
- ابنِ React/CSS/SVG/Components حقيقية.
- لا تعتمد على أبعاد الصورة كـ Canvas ثابت.
- Desktop / Laptop / Tablet / Mobile لكل منها توزيع مناسب.
- كل صفحة/فرع/نتيجة/تقرير تصل إلى 60–70% قوي ومستقر ثم: Verify -> Commit -> Save locally -> Move on.
- بعد اكتمال المنصة بالكامل نعود: 70% -> 80% -> 90% -> 100%.
